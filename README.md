### 🛒 01 / Budget Basket

<img src="https://img.shields.io/badge/BUDGET_BASKET-PLAYWRIGHT_%2B_TYPESCRIPT-7C3AED?style=for-the-badge" alt="Budget Basket — Playwright with TypeScript" />

**QA Test Engineer · Aptsol Global Tech Private Limited**

**Automation stack: Playwright · TypeScript**

Budget Basket is my primary project, with automation testing based on **Playwright and TypeScript**. My testing approach emphasizes clear scenarios, reusable code, and reliable validation of application behavior.

**Automation testing approach:**

- **Scenario design:** Translate requirements into positive, negative, and boundary scenarios with clear expected results.
- **Framework organization:** Structure tests, page objects, fixtures, and test data so responsibilities remain clear and changes are easier to maintain.
- **Page Object Model:** Keep page locators and reusable actions together, while keeping scenario assertions readable in test files.
- **Locators & synchronization:** Favor stable, user-facing locators and Playwright's auto-waiting and retrying assertions over fixed delays.
- **Test isolation & data:** Keep tests independent and prepare suitable data so one test's outcome does not determine another's result.
- **Authentication strategy:** Use reusable authentication setup where appropriate, while keeping login-specific tests separate from tests that require an authenticated user.
- **Assertions & validation:** Check visible messages, navigation, field validation, and expected UI state against the requirements.
- **Execution & diagnosis:** Organize smoke and regression coverage, and use Playwright reports, traces, and screenshots to investigate failures.
